# The Sophistication Gap

---

### Welcome

You're here because you want to use AI better. Not just use it—use it in a way that actually makes you more capable.

This workshop won't convince you that AI matters. You already know. What it will do is close the gap between how you're currently using AI and how the top performers use it.

The difference isn't about which tools you have. It's about how you think with them.

### Frequently Asked Questions

**Do I need to pay for any AI tools?**

No. Everything in this workshop is designed around free ChatGPT. We mention paid tools when they're genuinely better, but you don't need them.

**How long will this take?**

Video modules: ~40 minutes total. Exercises: 15-30 minutes each. You can complete everything in a few hours, or spread it over a week.

**Is this cheating?**

No. The protocols teach you to use AI as a thinking partner, not a ghostwriter. You do the work—AI helps you think about it more strategically. The goal is to learn more, not avoid learning.

**What if I get stuck?**

Use the AI Tutor. It's specifically designed to help you apply the protocols. Bring your real assignments and ask for guidance.

**Do I need to watch all the modules?**

Module 1 is essential context. Module 2 teaches the protocols—this is the core. Module 3 shows them in action—helpful but optional if you're confident. Module 4 is about the future—watch if you're curious.

**Can I share this with classmates?**

Yes. The more people using AI at mastery level, the better.
