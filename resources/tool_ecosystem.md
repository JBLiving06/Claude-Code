# AI Tool Ecosystem Reference

This is your companion guide to the AI tools mentioned in the workshop. Everything here is organized by what you're trying to do, not by tool name. Start with free options—upgrade only if you hit limitations.

---

## Research Tools

### Finding Academic Sources

| Tool | What It Does | Free Tier | Cost | When to Use |
|------|--------------|-----------|------|-------------|
| **Google Scholar** | Search academic papers, see citations | Unlimited | Free | Always start here for academic research |
| **Semantic Scholar** | AI-powered paper search, related papers | Unlimited | Free | When Google Scholar results are too broad |
| **Connected Papers** | Visual graph of related papers | 5 graphs/month | $3/mo | Understanding a research landscape visually |
| **Elicit** | AI paper search, extracts key info | 5,000 credits | $10/mo | Literature reviews, finding methodology details |
| **Consensus** | Answers research questions with paper evidence | Limited searches | $10/mo | Quick evidence checks, "what does research say about X" |

**Recommendation:** Start with Google Scholar (free). Add Elicit if you do heavy research.

### Synthesizing Sources

| Tool | What It Does | Free Tier | Cost | When to Use |
|------|--------------|-----------|------|-------------|
| **NotebookLM** | Upload sources, AI only uses those sources | Unlimited | Free | Research papers, studying from specific materials |
| **ChatGPT** | General synthesis, but may hallucinate | Limited | $20/mo Pro | Quick synthesis when you verify everything |
| **Claude** | Long documents, careful reasoning | Limited | $20/mo Pro | Dense readings, long PDFs, nuanced analysis |

**Recommendation:** NotebookLM is the best free option for academic work because it only uses your sources—no hallucinations.

### Current Information (News, Recent Data)

| Tool | What It Does | Free Tier | Cost | When to Use |
|------|--------------|-----------|------|-------------|
| **Perplexity** | AI search with source links | 5 Pro searches/day | $20/mo | Current events, recent statistics, fact-checking |
| **ChatGPT with browsing** | Web search integrated | Pro only | $20/mo | General current info (less precise than Perplexity) |

**Recommendation:** Perplexity free tier for occasional needs. Worth paying for if you need current info frequently.

## Quick Decision Guide

**"I need to write a research paper"**
→ Google Scholar (find sources) + NotebookLM (synthesize) + ChatGPT (rubric engineering, feedback)

**"I need to study for an exam"**
→ ChatGPT (practice questions) + NotebookLM (audio overviews) + Anki (if memorization-heavy)

**"I need to prepare for class"**
→ ChatGPT (pre-class prep protocol) + NotebookLM (if readings are dense)

**"I need to give a presentation"**
→ Gamma (first draft) or Google Slides (DIY) + ChatGPT (content help)

**"I need to learn to code"**
→ freeCodeCamp + ChatGPT (explanation) + GitHub Copilot (free for students)

**"I need current information with sources"**
→ Perplexity (best) or ChatGPT with browsing (Pro required)

## What This Workshop Uses

The four protocols in this workshop are designed around **free ChatGPT**. That's intentional—we want workflows that work for everyone.

If you have budget to upgrade one thing, here's the priority order:

1. **ChatGPT Pro ($20/mo)** — Faster, more reliable, longer conversations
2. **NotebookLM (free)** — You should be using this regardless
3. **Perplexity Pro ($20/mo)** — Only if you need current info frequently
4. **Claude Pro ($20/mo)** — Only if you work with very long documents

Most students do fine with free tools. Don't feel pressured to pay for things you don't need.
